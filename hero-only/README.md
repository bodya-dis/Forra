# FORRA RESIDENCE — только hero и просмотр фото при скролле

Копия основного проекта (`index.html` из репозитория `bodya-dis/Forra`), в которой остались:

- **Hero:** видео стройки, интро-анимация, заголовок, меню, кнопки, стеклянная плашка с цифрами, карточка с планом и подсказка Scroll down.
- **Просмотр фото при скролле:** план этажа раскрывается на весь экран, дальше по скроллу идут Living room → Bedroom → Bathroom со счётчиком, а потом снова hero.

Удалены секции About project и Our projects, переход-уголок, Dimensions (куб), Location (глобус), а также их CSS, JS и картинки. Стили и анимации hero и просмотра фото не менялись.

Пункты меню остались как в макете, но их секций в этой копии нет, поэтому по клику страница никуда не прокручивается.

## Запуск локально

Сборка не нужна. GSAP и ScrollTrigger подключаются с CDN, шрифты — с Google Fonts.

```bash
cd forra-hero
python3 -m http.server 8000
# открыть http://localhost:8000
```

Подойдёт любой статический сервер, например `npx serve`. Открывать сервером, а не двойным кликом: так видео и шрифты загружаются надёжно.
